# People Studio

Onboarding, reviews, recruitment and HR

Build onboarding flows, performance reviews, and goal/OKR tracking. Manage recruitment pipelines, leave policies, compensation bands, and employee directories, run engagement surveys and 360 feedback, and handle offboarding and referrals.
